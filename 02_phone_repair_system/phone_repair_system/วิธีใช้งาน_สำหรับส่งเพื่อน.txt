================================================================================
คู่มือการติดตั้งและใช้งาน: ระบบติดตามสถานะร้านซ่อมมือถือ (Mobile Phone Repair Status Tracking System)
สถาปัตยกรรม: Laravel 11.x + MySQL + Sanctum API + Flutter Web Client
================================================================================

[ 1. ขั้นตอนการเปิดใช้งานระบบ (One-Click Start) ]
--------------------------------------------------------------------------------
1. ตรวจสอบว่าในเครื่องติดตั้ง XAMPP เรียบร้อยแล้ว
2. เปิดโปรแกรม XAMPP Control Panel และกดปุ่ม [Start] ที่บริการ Apache และ MySQL
3. ดับเบิ้ลคลิกไฟล์ "start.bat" ที่โฟลเดอร์นอกสุดของโปรเจกต์เพียงครั้งเดียว
4. สคริปต์อัตโนมัติจะดำเนินการ:
   - ตรวจสอบและค้นหา PHP ของ XAMPP อัตโนมัติ
   - สร้างฐานข้อมูล 'phone_repair_db' ใน MySQL ให้อัตโนมัติ (ไม่ต้องเข้า phpMyAdmin เอง)
   - สร้างคีย์แอปพลิเคชัน (php artisan key:generate)
   - รันตารางฐานข้อมูลและใส่ข้อมูลเริ่มต้น (php artisan migrate:fresh --seed)
   - สั่งเปิดเว็บบราวเซอร์ 3 หน้าต่าง/แท็บพร้อมกันทันที
   - เริ่มการทำงานของเซิร์ฟเวอร์ที่พอร์ต 8080 (http://localhost:8080)

[ 4. รายละเอียดของ 3 หน้าต่าง/แท็บที่เปิดอัตโนมัติ ]
--------------------------------------------------------------------------------
แท็บ 1: http://localhost:8080/admin/dashboard
- หน้าเว็บฝั่ง Laravel Web พัฒนาด้วย Blade Templates + Tailwind CSS
- หน้าแผงควบคุมช่าง สรุปสถิติงานซ่อม ค้นหา กรองสถานะ และอัปเดตงานซ่อม
- รองรับทั้งหน้า Login, Register, เปิดใบรับซ่อม, จัดการประเภทงานซ่อม และติดตามสถานะ

แท็บ 2: http://localhost:8080/flutter
- หน้าเว็บฝั่ง Flutter Web Application (Single Page App) สไตล์ Material 3
- ใช้งานได้ทันทีโดยที่เครื่องเพื่อนไม่จำเป็นต้องติดตั้งโปรแกรม Flutter
- เชื่อมต่อ REST API สมบูรณ์แบบ 100% มีระบบ Login, Register, ค้นหาติดตามสถานะ,
  ยื่นแจ้งซ่อมใหม่, และแผงควบคุมของช่าง

แท็บ 3: http://localhost:8080/api-docs
- หน้าข้อมูล API แบบ Raw JSON ดิบล้วน 100% (Content-Type: application/json)
- ปราศจาก HTML/CSS ตกแต่งตามข้อกำหนดอย่างเคร่งครัด
- แสดงโครงสร้างตารางฐานข้อมูล 4 ตาราง และเอกสาร Endpoint ของระบบครบถ้วน


[ 5. โครงสร้างฐานข้อมูล MySQL (ตรงตามข้อกำหนดเข้มงวด 4 ตาราง รวม 24 ฟิลด์) ]
--------------------------------------------------------------------------------
1. users (6 ฟิลด์):
   - id (bigint, pk)
   - name (varchar)
   - email (varchar, unique)
   - password (varchar, hashed)
   - phone (varchar, unique)
   - role (enum: 'admin', 'user')

2. repair_types (4 ฟิลด์):
   - id (bigint, pk)
   - name (varchar)
   - base_price (decimal)
   - created_at (timestamp)

3. repair_tickets (8 ฟิลด์):
   - id (bigint, pk)
   - tracking_code (varchar, unique)
   - user_id (bigint, fk -> users.id)
   - repair_type_id (bigint, fk -> repair_types.id)
   - device_model (varchar)
   - issue_description (varchar)
   - status (enum: 'received', 'repairing', 'completed', 'cancelled')
   - created_at (timestamp)

4. repair_status_logs (6 ฟิลด์):
   - id (bigint, pk)
   - ticket_id (bigint, fk -> repair_tickets.id)
   - status (varchar)
   - note (varchar, nullable)
   - cost (decimal, nullable)
   - created_at (timestamp)

* รวมทั้งหมด 4 ตาราง จำนวน 24 ฟิลด์ (ไม่เกิน 30 ฟิลด์ตามข้อกำหนด)
